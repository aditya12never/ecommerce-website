## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/aditya12never/ecommerce-website.git
```

### 2. Navigate to the project

```bash
cd ecommerce-website
```

### 3. Open the project

Open the project folder in Visual Studio Code.

### 4. Run the application

If the project uses HTML, CSS and JavaScript, open `index.html` in your browser or use the Live Server extension.
